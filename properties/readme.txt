---------- HOW TO INSTALL ---------------
*Place the scs-telemtry.dll file in this folder:
'C:\Programs (x86)\Steam\steamapps\common\Euro Truck Simulator 2 or American Truck Simulator\bin\win_x64\plugins'
-----------------------------------------

------------ HOW TO USE -----------------
*Launch ktrack.exe and start the tracking when the game is launched.
*Your KaelysHUB credentials are required.
*Make sure to launch the app every time you want to track you deliveries.
